# О чем проект #
Проект представляет собой площадку для студентов и преподавателей под названием «TechInstHub».
Данный сайт предназначается для размещения важной информации (например, новостей, касающихся стажировок и мероприятий в ВУЗе);
для публикаций проектов и набора участников на них; для общения между студентами и преподавателями во время решения разных вопросов.

# Как работает платформа #
Студент регистрируется при входе на сайт. Студенту доступны проекты, новости, чаты.
Администратор регистрирует преподавателя. Преподаватель имеет возможность лпубликовать проекты, удалять их, принимать на них заявки, изучать новости, переписываться в чате.
Администратор выкладывает темы проектов, новости, добавляет (администратора/преподавателя), удаляет лишнюю информацию, логирует систему и создает SQL-запросы к базе данных.

# Установка #
1.  Клонируйте репозиторий:
    ```bash
    git clone https://github.com/alextochanka/TechInstHub
    cd TechInstHub
    ```
2.  Создайте и активируйте виртуальное окружение:
    ```bash
    python -m venv venv
    source venv/bin/activate
    ```
3.  Установите необходимые библиотеки:
    ```bash
    pip install -r requirements.txt

# Структура проекта #
1. app.py - файл с бэкэндом сайта.
2. templates/ - папка с HTML.
3. static/ - папка c CSS/JS, подгруженными изображениями, иконками и аватарками.
4. dump.sql - plain text для импортирования базы данных.
5. requirements.txt - список зависимостей.
